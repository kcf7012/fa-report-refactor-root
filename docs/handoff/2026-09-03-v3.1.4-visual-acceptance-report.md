## 2. 驗收 checklist 與結果

### Bug 1:Summary 疊加覆蓋 ✅ **PASS**

**稽核原始狀態**:Executive Summary / Key Improvements / 6 維度評分 **疊加在原 Summary 上**,造成原 Summary 內容被覆蓋。

**v3.1.2 修法**:重寫為新增獨立投影片(Executive / Key Improvements / 6 維度評分 各 1 張)

**驗收方法**:看 N160JCN slide 8 (Summary)、slide 19 (Executive Summary)、slide 21 (6 維度評分) 確認是獨立 3 張

**結果**:
- ✅ slide 8 是 Summary(只列原始 6 維度內容)
- ✅ slide 19 是 Executive Summary(獨立,只有一個 total_score + strengths 摘要)
- ✅ slide 21 是 6 維度評分(獨立,含橫條圖)
- 三者**完全沒有重疊**,**沒有覆蓋原 Summary**

### Bug 2:title placeholder 找錯 ✅ **PASS**

**稽核原始狀態**:「按一下即可新增文字」殘留在 layout 中(MS 多張)

**v3.1.2 修法**:`_safe_shape.py:get_title_placeholder()` 嚴格用 `placeholder_format.idx == 0` + 檢查 layout name 含「直排」則跳過

**驗收方法**:逐張掃描 56 張 PNG,找「按一下」「Click to add」等 placeholder 預設文字

**結果**:
- ✅ **0 處**殘留 placeholder 預設文字
- 所有 title 都有實際內容(報告標題、章節名稱)

### Bug 3:textbox 旋轉 90° ✅ **PASS**

**稽核原始狀態**:260811 多張 textbox 被旋轉 90°(母片 layout 含「直排」)

**v3.1.2 修法**:`_safe_shape.py:get_body_placeholder()` 檢查 layout name 含「直排/Vertical」→ 強制 orient='horiz' + rotation=0

**驗收方法**:260811 16 張全部看(母片含「Title and Vertical Text」)

**結果**:
- ✅ **0 張**有旋轉 textbox
- 所有文字保持橫向閱讀

### Bug 4:底部 placeholder 殘留 ✅ **PASS**

**稽核原始狀態**:N160JCN 多張底部 placeholder 殘留(原本應清空或移除)

**v3.1.2 修法**:重寫 `clean_unused_placeholders()` 從 slide 移除整個 placeholder 元素,在 orchestrator.execute 每個 action 後呼叫

**驗收方法**:N160JCN 21 張全部看

**結果**:
- ✅ **0 張**有底部殘留 placeholder
- ✅ **0 張**有「按一下即可新增文字」字樣
